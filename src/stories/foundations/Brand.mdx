  return (

export function Rule({ kind, children }) {
  const isNever = kind === 'never'
  return (
    <div className={`flex items-start gap-2 rounded-lg px-3 py-2 text-sm ${isNever ? 'bg-destructive/8 text-destructive' : 'bg-success/8 text-success'}`}>
      <span className="mt-0.5 shrink-0 font-bold">{isNever ? '✕' : '✓'}</span>
      <span>{children}</span>
    </div>
  )
}

# Brand

Visual identity for Nuwa — logo, colour, and usage rules for the `@ds/ui` component library.

## Logo mark

The Nuwa mark is built from three colour regions: a **brand-purple** wing (top-left), an **action-orange** corner (top-right), and **black** organic fills that anchor the form.

## Lockup

Pair the mark with the **nuwa** wordmark set in Geist&nbsp;Sans — semibold, tight tracking. Always maintain the horizontal alignment.

    </div>
    <div className="space-y-1">
      <Lockup size={32} textSize="text-xl" />
      <p className="font-mono text-[10px] text-muted-foreground">32 px — default</p>
    </div>
    <div className="space-y-1">

      <p className="font-mono text-[10px] text-muted-foreground">48 px — large</p>
    </div>
  </div>
</div>

**Mark-only** — use the mark alone only where space is too tight for the full lockup, or in contexts where multiple brand marks appear together (e.g. integration tiles).

**Minimum size** — never render the mark below **16 px**. The gradient details collapse and the shape reads as noise.

**Clear space** — keep a margin of at least **1× the mark's height** on all sides.

## Usage rules

<div className="not-prose flex flex-col gap-2 py-4">
  <Rule kind="do">Use the original SVG mark — never screenshot, screenshot-crop, or re-draw it.</Rule>
  <Rule kind="do">Use the mark on white, warm-light, dark-950, or dark-900 backgrounds.</Rule>
  <Rule kind="do">Scale uniformly — the mark is a square; keep equal width and height.</Rule>
  <Rule kind="do">Use <code translate="no">translate="no"</code> on the word "nuwa" in copy to prevent garbled auto-translation.</Rule>
  <Rule kind="never">Recolour, tint, or replace any part of the gradient fill.</Rule>
  <Rule kind="never">Place the mark on busy images, gradients, or pattern backgrounds without a solid backing.</Rule>
  <Rule kind="never">Stretch, rotate, or apply drop shadows to the mark.</Rule>
  <Rule kind="never">Use the mark below 16 px.</Rule>
  <Rule kind="never">Reproduce the mark in a single flat colour (the gradients are the identity).</Rule>
